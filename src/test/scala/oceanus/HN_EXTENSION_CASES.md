# HN extension regression cases

RTL stays frozen at 8a99c46. The mixed regression defaults to Retry disabled:
`oceanus.TestTop_L2PrefetchConflict --hn-extension=true --retry-percent=0 --mode=random --case=matrix --cycles=20000 --slices=S --level=L --seeds=1,2,3,4,5`.
Run S=1/2/4 and L=idle/light/medium/heavy/saturated: 75 distinct cases. Both DCT directions stay enabled: splitPercent=50 selects split reads; among the remaining reads, dctPercent=50 selects peer CompData. Six of every ten generated snoops are Fwd, two Stash and two ordinary, with the existing sparse snoops also retained. Explicit `--retry-percent=10/30/50` retains the Retry experiments.

Known-base mode prints `RETRY_BASE_KNOWN status=XFAIL` and exits successfully only after checking the specified signature. A changed signature or unrelated assertion/protocol error remains a failure. Omit `--expect-base-issue` to keep the raw failing reproductions. These XFAIL cases are counted separately from the Retry-off matrix; they are not functional passes. Retry-on random historical failures and their original logs are retained in `/data/zhuy/pf-v2/hn-extension/triage-20261028/`; unrelated Retry failures receive no blanket exemption.

`forwardTransactionCompleted` and `dctForwardComplete` count actual two-beat DCT forwarding; `fwdSnoop` includes invalid-line fallback and is a separate number. Window category `actualForward` starts on actual second DCT data beat, `requesterDCT` on first received peer CompData beat, `splitRead` on RespSepData receipt, and ordinary/Stash categories on actual SNP receipt. At each cycle c, per-line combinations use events in [c-511,c]. A window count increments only when a given line/combination changes from absent to present; overlapping cycles are recorded separately. One transaction uses either requester DCT or split responses; combinations of the two describe different transactions to the same cacheline. `forward` and active `forward` retain the broader pending Fwd-SNP meaning and must not be reported as actual DCT.

Coverage is for the existing read-only clean/SC/UC traffic. Stash SNP completion is not active Stash/DataPull coverage. Split writes, dirty/SD completeness and DVM remain outside this regression. ReadOnce stays **base 已知问题(见 /data/zhuy/pf-audit-tests/readonce-base-note.md)** and is not generated by this matrix.
